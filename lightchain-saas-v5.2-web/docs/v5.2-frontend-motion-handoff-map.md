### 4.2 Tab 指示器

| 项目 | 参数 |
| --- | --- |

### 4.3 首页右侧标签动效

| 对象 | 触发 | 参数 | 结束/回位 |
| --- | --- | --- | --- |
| 上标签漂浮 | 首页挂载后自动 | `y: 0 → -6px`；3.9s；`sine.inOut`；yoyo；无限 | 持续循环 |
| 下标签漂浮 | 首页挂载后自动 | `y: 0 → 6px`；4.4s；delay 0.7s；`sine.inOut`；yoyo；无限 | 持续循环 |

### 4.4 图片切换与兼容

- 首次挂载预加载深浅主题全部八张图片。
- 切 Tab 或主题时直接切换已预加载的活动图片。
- 不使用多张透明 PNG 交叉淡入，避免 Safari 闪图。
- 图片与整组动效均为装饰内容，`aria-hidden="true"`，不进入 Tab 顺序。
- 900px 及以下隐藏整组右侧动效，优先保证标题、Tab 和输入区。
- `prefers-reduced-motion` 下停止漂浮、避让和回位动画，保留静态图与标签。

## 7. 返回顶部按钮

| 项目 | 规则 |
| --- | --- |
| 显示条件 | 当前只读案例任务流 `scrollTop > 240px` |
| 隐藏条件 | 回到顶部附近，`scrollTop <= 8px` |
| 中间区间 | 8–240px 保持上一可见状态，避免临界点抖动 |
| 进入 | `opacity: 0 → 1`；`y: 4 → 0`；`scale: .94 → 1` |

| 缓动 | `easeOut` |

| reduced-motion | 按钮显隐无位移；滚动使用 `behavior: auto` |
| Tooltip | 文案“返回顶部”，显示在按钮左侧 |
| Tooltip 触发 | 鼠标悬停 300ms 后显示；键盘 `focus-visible` 时立即显示 |
| 明确不做 | 不变成向下箭头，不提供返回底部 |
| 投影 | `var(--shadow-l)`，深浅统一 |

## 8. 右下按钮定位与响应式

按钮不以浏览器视口右边为基准，而是吸附在**任务流主列右边**。

| 视口/详情栏状态 | 操作区 Grid |
| --- | --- |
| 无详情栏 | `minmax(0, 1fr) 64px` |
| 桌面详情栏 | `minmax(0, 1fr) 352px` |
| 详情参考信息展开 | `minmax(0, 1fr) 424px` |
| ≤1360 普通详情栏 | `minmax(0, 1fr) 288px` |
| ≤1360 参考信息展开 | `minmax(0, 1fr) 424px` |
| ≤900 详情栏隐藏 | 单列 `minmax(0, 1fr)` |

固定参数：

- 距任务流底部 24px；
- 距任务流主列右边 12px；
- 两按钮垂直间距 12px；
- 返回顶部在上，复制按钮在下；
- 两个按钮各自可点击，外层覆盖区 `pointer-events: none`。

禁止重新使用多组硬编码 `right: 64/352/424px`。那种写法在详情栏缩窄或隐藏时会让按钮相对视口漂移。

## 9. 统一 Token

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `--motion-standard` | `200ms ease-out` | 复制按钮展开、图标和文本过渡 |
| `--shadow-l` | `0 12px 28px -4px var(--overlay-weak)` | 返回顶部、复制按钮统一投影；与 Figma Shadow / L 的 y=12、blur=28、spread=-4 对齐 |
| `--radius-max` | `999px` | 两个悬浮按钮圆角；与 Figma 对齐 |
| `--overlay-weak` | 暗色 `rgb(0 0 0 / 20%)`；浅色 `rgb(0 0 0 / 5%)` | Shadow / L 主题颜色 |
| `--border-weak` | 暗色 `rgb(255 255 255 / 10%)`；浅色 `rgb(0 0 0 / 5%)` | 返回顶部按钮边框 |

不要为暗色模式单独写另一组黑色/青色发光投影；深浅主题都使用 `Shadow / L` Token，由 Token 自己负责主题兼容。
