## 2. 首页 Tab 与右侧动效

### 业务映射

| activeTab | 业务 | dark 图片 | light 图片 | 上标签 | 下标签 |
| ---: | --- | --- | --- | --- | --- |
| 0 | 商品企划 | `archive-header-product-planning.png` | `archive-header-product-planning-light.png` | 精准选品 | 市场洞察 |
| 1 | 客户提案 | `archive-header-client-proposal-dark.png` | `archive-header-client-proposal-light.png` | 高效沟通 | 创意提案 |
| 2 | 服装设计 | `archive-header-fashion-design.png` | `archive-header-fashion-design-light.png` | 个性定制 | 潮流设计 |
| 3 | 图案设计 | `archive-header-pattern-design.png` | `archive-header-pattern-design-light.png` | 视觉吸引 | 原创图案 |

主视觉按 240 × 172 CSS px 显示；切换 Tab 或主题时直接替换已预加载的活动图片。

### 动效参数

| 对象 | 参数 |
| --- | --- |
| Tab 指示器 | `left`、`width`；0.28s；`power2.out` |
| 上标签漂浮 | `y: 0 → -6px`；3.9s；`sine.inOut`；yoyo；无限 |
| 下标签漂浮 | `y: 0 → 6px`；4.4s；delay 0.7s；`sine.inOut`；yoyo；无限 |
| 鼠标避让 | 标签中心 96px 半径；最大位移 18px |
| 上 / 下标签回位 | 0.46s / 0.5s；`power3.out` |

- 只响应鼠标；触屏和手写笔不触发避让。
- 预加载四个业务的深浅主题共 8 张图片。
- 900px 及以下隐藏整组右侧动效。
- `prefers-reduced-motion` 下停止漂浮和避让，保留静态内容。
- 整组内容为装饰元素，`aria-hidden="true"`。

## 3. 只读案例右下操作

### 案例复用

| 状态 | 表现 |
| --- | --- |
| 默认 | 40 × 40，只显示 24px copy icon |
| Hover / focus-visible | 向左展开；水平内边距 16px；文字宽度按中、英、日内容自适应 |
| 动效 | `width`、`padding`、图标 opacity / scale、文字 opacity / translate；`--motion-standard` |
| 样式 | `--radius-max`、`--shadow-l` |

点击后将案例第一句需求回填到对应业务和企划类型的首页输入区；只生成草稿，不自动发送或创建任务。

### 返回顶部

| 项目 | 参数 |
| --- | --- |
| 显示 | `scrollTop > 240px` |
| 隐藏 | `scrollTop <= 8px` |
| 进入 / 退出 | `opacity + y + scale`；0.16s；`easeOut` |
| 点击 | 当前 `.conversation-scroll` 滚动到 `top: 0` |
| Tooltip | “返回顶部”，显示在按钮左侧 |

### 定位

- 操作区吸附任务流主列右侧，不以浏览器视口为基准。
- 距任务流底部 24px，距主列右边 12px。
- 两个按钮垂直间距 12px；返回顶部在上，案例复用在下。
- 详情栏宽度为 352px，参考信息展开为 424px；≤1360 时普通详情栏为 288px；≤900 时切为单列。
