# Lightchain SaaS v5.2 首页实现规格

## 范围

- React + TypeScript + Tailwind CSS。
- 首版仅提供简体中文。
- 1920 × 1080 为基准画布，兼容常见 14 寸笔记本视口。
- 主内容版心固定 720px，不做整页缩放。
- 项目全部位于 `lightchain-saas-v5.2-web` 独立目录。

## 布局

- TopBar 固定高度 48px。
- 左侧栏默认展开，宽 352px；用户可切换至 72px 收起态。
- 侧栏状态不由断点自动更改。
- 720px 版心始终在侧栏之外的剩余内容区域内居中。
- 低高度视口只压缩外部垂直留白，核心组件尺寸保持不变。

## 交互

- 语言选择器当前固定为简体中文。
- 语言选择器右侧增加 32 × 32px 主题按钮；暗色显示月亮，浅色显示太阳。
- 快速开始支持展开和收起，卡片有 hover 状态。
- 输入框支持 Enter 发送、Shift + Enter 换行。
- 图片使用从 Figma 下载的资产；缺失内容使用固定尺寸占位框。

## Motion

- 初始化态右侧的前后玻璃卡片使用 Figma Motion 参数。
- 时间线 5 秒，boomerang 往返无限循环。
- 后层旋转 0° → 5°，位移 x 0 → 1.317、y 0 → -15.084。
- 前层旋转 0° → -20°，位移 x 0 → -3.923、y 0 → -10.25。
- 动画只改变 transform，避免触发布局计算和页面抖动。
